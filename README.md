# 🚀 Toast Notification Tool

A simple web tool to show toast notifications: ✅ Success, ❌ Error, ⚠️ Warning, ℹ️ Info. Built using HTML, CSS, and JavaScript.  


## ✨ Features  


- 4 Types of toasts  
- Smooth auto-dismiss  
- Clean and modern UI


## 🛠️ Tech Used  


- HTML5*  
- CSS*  
- JavaScript*
  

## 📦 How to Use  


1. Open `index.html` in your browser.  
2. Click a button to show a toast.  
3. Toast disappears after a few seconds.
